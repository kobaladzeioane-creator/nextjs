# nextjs

# 🚀 Next.js Course - Learning Repository

ეს რეპოზიტორი შექმნილია **Next.js**-ის სასწავლო კურსის ფარგლებში. პროექტი მოიცავს ფრეიმვორკის ძირითად და advanced კონცეფციებს, როგორიცაა App Router, დინამიური მარშრუტიზაცია (Dynamic Routing), Catch-all Routes, Server & Client Components, Server Actions და ბაზასთან/API-ებთან ინტეგრაცია.

---

## 🛠️ ტექნოლოგიები (Tech Stack)

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Library:** [React](https://react.dev/)
* **Language:** TypeScript / JavaScript
* **Styling:** Tailwind CSS / CSS Modules

---

## 📌 ძირითადი თემები & ფუნქციონალი

* 📁 **App Router Architecture:** ფოლდერების სტრუქტურაზე დაფუძნებული როუტინგი (`app/` დირექტორია).
* 🛣️ **Routing & Navigation:**
  * Static Pages (`/about`, `/contact`)
  * Dynamic Routes (`/products/[id]`)
  * Catch-all Routes (`/docs/[...slug]`)
  * Nested Layouts & Templates
* ⚡ **Rendering Strategies:** Server-Side Rendering (SSR), Static Site Generation (SSG), Client-Side Rendering (CSR).
* 🔄 **Data Fetching:** Server Components Fetch, SWR / React Query.
* ⚙️ **Server Actions & API Routes:** სერვერული ლოგიკისა და ფორმების დამუშავება.
